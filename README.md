# 🎂 День Рождения Асель Молдабековой

Космическое приглашение на день рождения с вишлистом и RSVP.

## 🚀 Деплой на GitHub Pages (пошагово)

### Шаг 1. Создайте репозиторий на GitHub
1. Зайдите на [github.com](https://github.com) (создайте аккаунт, если нет)
2. Нажмите **"+"** → **"New repository"**
3. Назовите: `asel-birthday`
4. Оставьте **Public**
5. Нажмите **"Create repository"**

### Шаг 2. Загрузите файлы
**Вариант А — Через GitHub (без командной строки):**
1. В репозитории нажмите **"uploading an existing file"**
2. Перетащите **все файлы и папки** из скачанного архива
3. Нажмите **"Commit changes"**

**Вариант Б — Через терминал:**
```bash
git clone https://github.com/ВАШ_USERNAME/asel-birthday.git
cd asel-birthday
# Скопируйте сюда все файлы из архива
git add .
git commit -m "Initial commit"
git push origin main
```

### Шаг 3. Включите GitHub Pages
1. В репозитории → **Settings** → **Pages**
2. В разделе **"Build and deployment"** выберите **Source**: **GitHub Actions**
3. Сохраните

### Шаг 4. Готово!
После пуша GitHub автоматически соберёт и опубликует сайт.
Ваша ссылка будет:

```
https://ВАШ_USERNAME.github.io/asel-birthday/
```

Подождите 1–2 минуты, затем откройте ссылку.

Ту же ссылку `https://ВАШ_USERNAME.github.io/asel-birthday/` отправьте гостям — они увидят приглашение и смогут бронировать подарки.

## ⚠️ Важно
Если вы измените название репозитория, обновите `base` в `vite.config.js`:
```js
base: '/НОВОЕ_ИМЯ_РЕПОЗИТОРИЯ/',
```
